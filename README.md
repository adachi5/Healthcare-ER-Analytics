# 🏥 Healthcare Emergency Room Analytics

## Project Overview

This project analyzes emergency room patient data using SQL and Tableau to uncover trends in patient referrals, department wait times, patient satisfaction, and emergency room visit volume.

The project demonstrates the complete data analysis process, from querying and validating data with SQL to building interactive dashboards in Tableau.

---

## Tools Used

- PostgreSQL
- SQL
- Tableau Public
- Microsoft Excel

---

## Dataset

This project uses a healthcare emergency room dataset containing patient demographics, referral departments, admission status, wait times, patient satisfaction scores, and visit dates.

---

## Business Questions

- Which referral departments receive the highest number of patients?
- Which departments have the longest average patient wait times?
- How do emergency room visits change throughout the year?
- Does patient satisfaction differ across racial groups?

---

# Dashboard 1: Emergency Room Operations

![Emergency Room Operations](Emergency%20Room%20Performance%20Dashboard.png)

### Key Findings

- Walk-In patients accounted for the largest number of emergency room visits.
- Neurology had the highest average patient wait time.
- Emergency room visits increased during the spring and summer months before declining toward the end of the year.

---

# Dashboard 2: Patient Experience

![Patient Experience](Patient%20Experience%20Dashboard.png)

### Key Findings

- Patient satisfaction scores remained relatively consistent across racial groups.
- Satisfaction scores ranged from approximately **4.8 to 5.3**.
- Overall patient satisfaction remained stable across the patient population.
